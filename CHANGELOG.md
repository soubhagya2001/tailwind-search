# Changelog

All notable changes to the "tailwind-search" extension will be documented in this file.

## [2.0.0] - 2024-02-07

### Added
- **IntelliSense 2.0**: High-performance code completion with real-time CSS property details for 39k+ Tailwind classes.
- **Quick Navigation**: A new "Jump to section" feature with Intersection Observer for active heading highlighting.
- **Improved Search**: Robust fuzzy search algorithm that handles typos and relevance ranking.
- **History Management**: Added a "Recently Used" section with a clear-all feature.
- **Collapsible Cards**: Redesigned the UI into clean, collapsible cards for better organization.
- **Official Documentation Links**: Direct access to Tailwind docs integrated into every card header.
- **Clear Search**: Added a clear icon to the search input for quick resetting.

### Changed
- **Revamped UI**: Complete visual overhaul using VS Code's modern design tokens for a native feel.
- **Auto-Theming**: Improved automatic theme matching (Dark/Light/High Contrast).
- **Auto-Close Dropdowns**: Dropdowns now automatically close when clicking back into the editor.

### Fixed
- Fixed IntelliSense activation triggers in HTML and React files.
- Fixed layout shifting issues in narrow sidebar widths.
